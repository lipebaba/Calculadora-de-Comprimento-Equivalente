# 📐 Calculadora de Comprimento Equivalente

Calculadora de comprimento equivalente de tubulações hidráulicas, desenvolvida em **HTML, CSS e JavaScript** como projeto para a disciplina de **Fenômenos de Transporte**.

## 📌 Sobre o projeto

A aplicação permite selecionar materiais, diâmetros e conexões, calcular o comprimento equivalente total, importar e exportar projetos e gerar um memorial de cálculo para impressão ou PDF.

O projeto une teoria e prática, utilizando a programação como apoio à compreensão e à resolução de problemas envolvendo o escoamento em tubulações hidráulicas.

## 🚀 Funcionalidades

- Seleção de materiais, diâmetros e conexões.
- Cálculo do comprimento equivalente total.
- Importação e exportação de projetos.
- Geração de memorial de cálculo para impressão ou PDF.

## 🛠️ Tecnologias utilizadas

- **HTML:** estrutura da aplicação.
- **CSS:** estilização e apresentação da interface.
- **JavaScript:** lógica dos cálculos e interatividade.

## 🎓 Objetivo acadêmico

Aplicar os conhecimentos adquiridos na disciplina de **Fenômenos de Transporte**, desenvolvendo uma ferramenta que auxilie nos cálculos e no entendimento do comprimento equivalente em tubulações hidráulicas.
