# 📐 Calculadora de Comprimento Equivalente

Projeto desenvolvido para a disciplina de **Fenômenos de Transporte**, com o objetivo de aplicar os conceitos estudados em sala de aula por meio de uma calculadora de comprimento equivalente.

## 📌 Sobre o projeto

A proposta é facilitar o estudo do comprimento equivalente em tubulações, relacionando os conhecimentos de Fenômenos de Transporte ao desenvolvimento de uma ferramenta digital.

O projeto une teoria e prática, utilizando a programação como apoio à compreensão e à resolução de problemas da disciplina.

## 🎓 Objetivo acadêmico

Aplicar os conhecimentos adquiridos na disciplina de **Fenômenos de Transporte**, desenvolvendo uma solução que auxilie nos cálculos e no entendimento do conteúdo.

## 🌐 Site hospedado

O site está hospedado e disponível para utilização online, permitindo acessar a calculadora diretamente pelo navegador.
